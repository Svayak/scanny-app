Funktioner

Det här gör kiosken

Scanny är en webbapp för verkstadens lager. Den körs på Azure och kan installeras som PWA.

▦
Streckkod via HID eller tangentbord
Kiosken tar emot streckkoder från en HID-läsare, till exempel Zebra, eller från tangentbordet.
!
Beställningsnivå och kritisk nivå
Beställningsnivån lägger artikeln i beställningslistan. När saldot passerar kritisk nivå kan ett e-postlarm skickas till den adress som är inställd.
@
Beställning via e-post
Beställningar kan skickas manuellt med e-post. På Standard och Pro kan utskicket också schemaläggas till en veckodag och tid.
↗
Fordonslogg
Uttag kan kopplas till ett fordon. På Standard och Pro kan underlaget skrivas ut eller sparas som PDF.
●
Användare och PIN
Personal väljer sitt namn på kiosken. Har användaren en PIN-kod krävs den. Behörigheter styr vem som får skanna, fylla på och inventera.
#
Inventering
Lagret kan räknas i inventeringsläge. På Standard och Pro kan en rapport sparas och skickas med e-post.
▤
Etiketter
Etiketter kan skrivas ut till en Brother QL-810W via en lokal brygga på en dator i verkstaden.
↓
Händelselogg
Uttag, påfyllning och andra händelser loggas. Loggen kan exporteras som CSV.
Kiosk

Kiosk i webbläsaren

Personal väljer användare och PIN, väljer uttag, påfyllning eller inventering, och skannar. Kiosken kan installeras som PWA.

✓ Återgår till uttag efter 10 minuter
✓ Ljud och färg vid skanning
✓ HID-streckkodsläsare, till exempel Zebra, eller tangentbord
✓ Kan installeras som PWA

Fyra steg i appen

Det finns ingen självregistrering på den här sidan. Kontot sätts upp efter kontakt.

1
Hör av er
Kontakta oss för pris och för att få ett konto. Det går inte att skapa konto själv på scanny.se.
2
Lägg in produkter
Produkter kan läggas in manuellt, med streckkod, eller importeras från CSV.
3
Öppna kiosken
Kiosken öppnas i webbläsaren. Personal väljer användare och PIN och skannar med HID-läsare eller tangentbord.
4
Beställ och larma via e-post
Beställningar kan skickas manuellt. På Standard och Pro kan de också gå enligt schema. Kritisk nivå kan ge e-postlarm.
